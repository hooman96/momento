# API Reference — Open Router Backend

**Base URL:** `http://localhost:8005`
**Interactive docs:** `http://localhost:8005/docs` (Swagger UI) · `http://localhost:8005/redoc` (ReDoc)

---

## Data Types

### TokenUsage

Token counts returned by the model provider.

| Field | Type | Description |
|-------|------|-------------|
| `prompt_tokens` | `int` | Tokens in the input (system prompt + user prompt). |
| `completion_tokens` | `int` | Tokens generated by the model. |
| `total_tokens` | `int` | `prompt_tokens + completion_tokens`. |

### ModelResult

Full result for a single model completion.

| Field | Type | Description |
|-------|------|-------------|
| `text` | `string` | The model's reply. Empty string on error. |
| `usage` | `TokenUsage \| null` | Token counts. Null if the provider didn't return usage data or the call errored. |
| `elapsed_ms` | `int` | Wall-clock time for the API round-trip in milliseconds. |
| `tokens_per_second` | `float \| null` | Generation speed: `completion_tokens / (elapsed_ms / 1000)`. Null when usage is unavailable. |
| `error` | `string \| null` | Error message if the call failed; `null` on success. |

## Endpoints

### `GET /` — Health Check

Returns service status and available endpoints.

**Response `200`:**

```json
{
  "service": "Open Router Backend",
  "status": "ok",
  "endpoints": {
    "POST /chat": "Route prompt to models (optional system_prompt, model_ids)",
    "POST /support": "Support/onboarding reply (prompt, mode: customer_support|onboarding)",
    "GET /models": "List default model IDs and display names"
  }
}
```

### `POST /chat` — Generic Chat

Send a prompt to one or more models with an optional system prompt.

**Headers:**

| Key | Value |
|-----|-------|
| Content-Type | `application/json` |

**Request body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `prompt` | `string` | **Yes** | User message (min 1 character). |
| `system_prompt` | `string \| null` | No | Optional system instruction applied to every model. |
| `model_ids` | `string[] \| null` | No | Model IDs to query. Defaults to all 5 free models if omitted. |

**Example — minimal (all models, no system prompt):**

```json
{
  "prompt": "What are your opening hours?"
}
```

**Example — with system prompt and specific models:**

```json
{
  "prompt": "How do I reset my password?",
  "system_prompt": "You are a helpful assistant. Answer in one short paragraph.",
  "model_ids": [
    "openai/gpt-oss-20b:free",
    "meta-llama/llama-3.3-70b-instruct:free"
  ]
}
```

**Response `200`:**

```json
{
  "responses": {
    "openai/gpt-oss-20b:free": {
      "text": "Our opening hours are Monday–Friday, 9 AM to 5 PM.",
      "usage": {
        "prompt_tokens": 14,
        "completion_tokens": 22,
        "total_tokens": 36
      },
      "elapsed_ms": 1842,
      "tokens_per_second": 11.9,
      "error": null
    },
    "meta-llama/llama-3.3-70b-instruct:free": {
      "text": "We're open from 9 to 5, Monday through Friday.",
      "usage": {
        "prompt_tokens": 14,
        "completion_tokens": 18,
        "total_tokens": 32
      },
      "elapsed_ms": 2105,
      "tokens_per_second": 8.6,
      "error": null
    }
  }
}
```

**Response when a model errors (still `200` — error is per-model):**

```json
{
  "responses": {
    "openai/gpt-oss-20b:free": {
      "text": "",
      "usage": null,
      "elapsed_ms": 503,
      "tokens_per_second": null,
      "error": "Rate limit exceeded: free-models-per-day."
    }
  }
}
```

**Response `422`** — Validation error (e.g. empty prompt):

```json
{
  "detail": [
    {
      "loc": ["body", "prompt"],
      "msg": "ensure this value has at least 1 characters",
      "type": "value_error.any_str.min_length"
    }
  ]
}
```

**Response `500`** — Unexpected server error.

### `POST /support` — Support / Onboarding Chat

Like `/chat`, but uses **built-in system prompts** for customer support or onboarding instead of a custom one.

**Headers:**

| Key | Value |
|-----|-------|
| Content-Type | `application/json` |

**Request body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `prompt` | `string` | **Yes** | User message (min 1 character). |
| `mode` | `string` | No | `"customer_support"` (default) or `"onboarding"`. |
| `model_ids` | `string[] \| null` | No | Model IDs to query. Defaults to all 5 free models if omitted. |

**Example — customer support (default):**

```json
{
  "prompt": "I can't log in. What should I do?",
  "mode": "customer_support"
}
```

**Example — onboarding with specific models:**

```json
{
  "prompt": "What are the first steps after signup?",
  "mode": "onboarding",
  "model_ids": ["google/gemma-3-27b-it:free", "z-ai/glm-4.5-air:free"]
}
```

**Response `200`:**

```json
{
  "responses": {
    "google/gemma-3-27b-it:free": {
      "text": "Welcome! Here's how to get started...",
      "usage": {
        "prompt_tokens": 42,
        "completion_tokens": 85,
        "total_tokens": 127
      },
      "elapsed_ms": 3210,
      "tokens_per_second": 26.5,
      "error": null
    },
    "z-ai/glm-4.5-air:free": {
      "text": "Great question! First, complete your profile...",
      "usage": {
        "prompt_tokens": 42,
        "completion_tokens": 72,
        "total_tokens": 114
      },
      "elapsed_ms": 2800,
      "tokens_per_second": 25.7,
      "error": null
    }
  }
}
```

**Response `400`** — Invalid mode:

```json
{
  "detail": "mode must be 'customer_support' or 'onboarding'"
}
```

## Endpoint Summary

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/` | Health check and endpoint list |
| `GET` | `/models` | Default model IDs and display names |
| `POST` | `/chat` | Generic multi-model chat with optional system prompt |
| `POST` | `/support` | Support/onboarding chat with preset system prompts |

---

## Error Handling

Errors are handled at two levels:

1. **Per-model errors** — If a single model fails (rate limit, timeout, etc.), the overall response is still `200`. The failing model's entry will have `error` set and `text` empty.
2. **Request-level errors** — Invalid input returns `422`, invalid mode returns `400`, and unhandled exceptions return `500`.

---

## Notes

- All `POST` bodies must be **JSON** with `Content-Type: application/json`.
- `elapsed_ms` measures the full round-trip to Open Router (network + inference). It uses a high-resolution monotonic clock (`time.perf_counter`).
- `tokens_per_second` is computed as `completion_tokens / (elapsed_ms / 1000)`. This reflects end-to-end throughput including network latency, not pure model inference speed.
- Token usage depends on the provider. Most Open Router models return `prompt_tokens`, `completion_tokens`, and `total_tokens`. If the provider omits usage data, `usage` will be `null`.
- CORS is open (`*`) for development. Restrict origins in production.
